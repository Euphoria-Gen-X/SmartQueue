# SmartQueue
SmartQueue – Web-Based Appointment &amp; Queue Management System

➡️ Customers can view and book available slots
➡️ Receive confirmations via Email or SMS
➡️ Admin can manage the ca;ender, assign tokens and monitor real-time queue status

🔥 AI is integrated to predict peak booking slots available based on previous data

🔥 QR Code System that will allow fast check-ins at the front desk improving efficiency.
